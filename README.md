# Factor Lab

Стенд команды 3 для сравнения NPV и минимального стрессового ΔNPV портфеля между датами. Получает кривую MOEX и шесть сценариев от команды 2, а графики платежей и оценки — из HTTP-калькулятора команды 1. Версия калькулятора закреплена в Compose.

Укажите в `CURVES_URL` адрес API команды 2, доступный из Docker. Например, для локального сервиса на macOS используйте `http://host.docker.internal:8001`.

```sh
export CURVES_URL=http://host.docker.internal:8001
docker compose up --build -d
```

Откройте [Swagger](http://127.0.0.1:8000/docs). Выполните `POST /api/v1/runs` с телом `{"dates":["2022-08-31","2022-09-30"]}` и подставьте полученный `id` в `GET /api/v1/runs/{run_id}`. Даты примера требуют архивных кривых сервиса. Для повторяемой проверки можно запустить `python3 scripts/smoke_integration.py`.

Шепли разлагает изменение между датами на календарь и погашения, а также три участка кривой. Отдельная модель оценивает связи характеристик сделки с NPV или стрессовой чувствительностью. Состав портфеля прокатывается от одного среза, включая выбытие погашенных сделок. Досрочное погашение можно явно включить параметром `prepayment`. Интерфейс этой ветки доступен через HTTP API и Swagger.
