# Factor Lab

Учебный стенд команды 3 для анализа NPV/dNPV и влияния параметров кредитов и кривых. Интеграция с [калькулятором команды 1](https://github.com/F14my/cashflow-rs) закреплена в `engine.lock.json`.

Запуск из корня проекта: `python3 scripts/bootstrap.py --install-rust`, затем `python3 scripts/run.py`. Открыть http://127.0.0.1:8000. Нужны Python 3.11+, Node.js 22.12+ и компилятор C/C++.
